# ig-research

Skill de Claude Code para investigar el contenido top de Instagram en cualquier nicho:
scrapea posts, descarga y transcribe los reels top, captura los hooks y produce un
informe HTML con diseño de marca.

## Instalación

```bash
cp -r ig-research ~/.claude/skills/
cd ~/.claude/skills/ig-research && npm install
```

Dispara con `/ig-research`.

## Nota

`chrome-profile/` (sesión del navegador) y `projects/` (datos scrapeados) están en
`.gitignore` y no se publican.
